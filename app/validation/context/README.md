# Bundled Linked Art context

`linked-art.json` is third-party context data from the
[Linked Art project](https://linked.art/), associated with the v1 context URL
<https://linked.art/ns/v1/linked-art.json>.

This file is copied unchanged from `app/validation/context/linked-art.json`
in prototype commit `45f6c3f` of this repository. Its original upstream commit
and download date were not recorded; the v1 URL is not an immutable release pin.

record an immutable upstream revision, refresh the checksum and rerun the
validation tests. Original upstream revision provenance remains to be confirmed.
